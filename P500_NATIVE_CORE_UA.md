# Native Core для LG P500

## Мета

Зменшити залежність від старого WebView Android 2.3 і залишити в пам’яті лише інтерфейс, необхідний для щоденного керування ПК.

## Оптимізації

1. `NativeCoreActivity` не містить WebView.
2. Профілі кешуються окремо для кожного ПК.
3. Стартовий endpoint поєднує bootstrap і status.
4. Опитування статусу: активний режим, простій і backoff після помилок.
5. Мережеві черги мають жорстку місткість і не ростуть безмежно.
6. Рухи тачпада накопичуються й відправляються пакетами кожні 60–200 мс.
7. У DOM нічого не завантажується, доки користувач не відкриє вебінструменти.
8. Максимум шість кнопок профілю та чотири постійні вкладки.
9. Профілі, команди й дозволи фільтруються сервером для конкретного токена.
10. Після втрати сервера кешована панель залишається видимою, а повторні спроби виконуються з backoff.

## Обмеження

Фактичне використання RAM, плавність ARMv6, час старту та поведінка під CyanogenMod 7.2 можуть бути остаточно підтверджені лише після складання APK і тесту на фізичному P500.
