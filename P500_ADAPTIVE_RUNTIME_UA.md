# P500 Adaptive Runtime

PocketBridge v1.3.1 додає адаптивне виконання для LG Optimus One P500. Мета — зменшити створення Java-об’єктів, мережевий трафік і фонову активність без втрати основного керування.

## Рівні

- **ECO** — слабка батарея, тиск пам’яті, кілька мережевих помилок або висока затримка.
- **BAL** — типовий режим для P500.
- **FAST** — доступний лише на пристроях із більшим heap і стабільною швидкою мережею.

Рівень впливає на:

- частоту статусних запитів;
- частоту запитів медіаінформації;
- інтервал пакетів тачпада;
- розмір локальних черг;
- швидкість повторного підключення.

## Фіксований пул кнопок

Головна панель більше не створює нові `Button` і рядки розкладки при кожному перемиканні профілю. Шість кнопок оголошено в XML один раз, після чого змінюються лише текст, стиль, видимість і прив’язана команда.

Це скорочує:

- короткочасні об’єкти;
- паузи збирача сміття;
- повторні layout-pass;
- ризик ривків під час перемикання профілю.

## Умовний bootstrap

`GET /api/p500/native/bootstrap` підтримує `ETag` і `If-None-Match`.

Якщо профілі, дозволи та конфігурація не змінилися, сервер повертає `304 Not Modified`. APK використовує локальний bootstrap і завантажує тільки компактний статус.

## Компактні команди

Native Core використовує:

```http
POST /api/p500/cmd
POST /api/p500/input
```

Команди передають короткі поля, наприклад:

```json
{"a":"volume_up","c":false}
```

Рух миші:

```json
{"e":"m","x":12,"y":-4,"d":0}
```

Старі маршрути `/api/action` і `/api/input/*` збережено для сумісності.

## GZip

Android-клієнт явно запитує `gzip` і вміє розпаковувати відповідь через `GZIPInputStream`. Bootstrap стискається серверним GZip middleware, а компактні статуси зазвичай залишаються без стиснення, бо їхній розмір менший за накладні витрати GZip.

## Поведінка при нестачі пам’яті

`onLowMemory()`:

- переводить governor в ECO;
- збільшує інтервал опитування;
- зупиняє найближчий статусний таймер;
- скидає ETag, щоб наступний повний bootstrap перевірив кеш;
- не видаляє кнопки активного профілю, тому пульт залишається придатним до роботи.

## Налаштування

У налаштуваннях APK є перемикач:

```text
Adaptive Runtime: підлаштовувати мережу, батарею та RAM
```

Він увімкнений за замовчуванням. Після вимкнення використовується стабільний збалансований режим.

## Діагностичний рядок

У нижній частині Native Core відображається скорочена інформація:

```text
BAL · heap 7/24MB · 86мс · 94B · q0
```

Це рівень governor, використаний heap, усереднена затримка, розмір останньої відповіді та довжина черги.
