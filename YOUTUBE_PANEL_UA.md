# Панель керування YouTube

PocketBridge 1.4.0 / Android 1.8.0 додає нативну сторінку **YT**, оптимізовану для LG P500.

## Доступні команди

- відкрити та активувати вікно YouTube;
- Play / Pause;
- попереднє та наступне відео;
- перемотування на 10 секунд;
- гучність відео та Mute;
- повноекранний і театральний режими;
- субтитри;
- зміна швидкості відтворення;
- пошук із телефона.

Команди керують активною вкладкою YouTube через офіційні клавіатурні скорочення. Сервер перед кожною командою намагається активувати вікно браузера, у заголовку якого є `YouTube`. Якщо вікно не знайдено, спочатку натисни **Відкрити**. Після першого відкриття відео один раз клацни програвач на ПК: YouTube вимагає фокус програвача для частини клавіатурних команд.

## Автоматичний профіль

Коли активне вікно Chrome, Edge, Firefox, Opera, Brave або Vivaldi має `YouTube` у заголовку, Smart Profiles пропонує профіль `YouTube` з пріоритетом 100.

## Дозволи

Основні кнопки потребують дозволу `actions`. Пошук потребує лише `actions`: сервер відкриває URL результатів пошуку без віддаленого введення тексту.
