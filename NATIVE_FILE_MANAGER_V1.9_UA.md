# PocketBridge 1.9.0 — Native File Manager

Версія 1.9.0 додає нативний файловий менеджер для LG P500 і Redmi Note 9 Pro без використання WebView.

## Можливості

- перегляд спільної папки PocketBridge;
- перехід між вкладеними папками;
- завантаження файла з ПК у `Download/PocketBridge` на Android;
- передавання вибраного Android-файла у поточну папку на ПК;
- створення папок;
- видалення файлів та порожніх папок довгим натисканням;
- компактний API для слабкого LG P500;
- одноразові 30-секундні посилання на завантаження;
- захист від path traversal, Windows ADS і системних зарезервованих імен.

## Увімкнення

На ПК відкрий `open_editor.bat`, увімкни **Обмін файлами** та задай максимальний розмір файла.

Для вже спарованого телефона відкрий `open_devices.bat` і додай дозвіл **Файловий обмін**. Нові спарювання включають цей дозвіл до рекомендованого набору.

На телефоні:

```text
Native Core → Ще → Файли ПК
```

Коротке натискання на папку відкриває її. Коротке натискання на файл завантажує його. Довге натискання відкриває підтвердження видалення.
